# 行为准则（Code of Conduct）

## 我们的承诺

为了让这个社区对所有人都友好，贡献者与维护者承诺：无论年龄、体型、可见或不可见的
残障、族裔、性别认同与表达、经验水平、国籍、外貌、种族、宗教、性取向，
参与项目的每个人都不受骚扰。

## 具体一点

** welcomed 的行为**：

- 对新手的问题保持耐心 —— 这个项目的目标用户正是"刚装完系统的人"
- 报告问题时按模板给出环境信息，这让别人能帮到你
- 指出问题时对事不对人，能给出证据或复现步骤最好
- 接受"这不是 bug，是 Windows 的行为"这类解释，并愿意先查 SPEC §13 的决策表

**不可接受的行为**：

- 骚扰、人身攻击、歧视性言论
- 发布他人的私人信息（doxxing）
- 在 issue 里刷屏、灌水、发布与项目无关的广告
- 恶意夸大安全漏洞的严重性以索取赏金

## 范围

适用于项目的所有空间（issue、PR、讨论区），也适用于代表项目的公开场合。

## 执行

发现违规请用 [Private vulnerability reporting](https://github.com/xinghe-labs/devkit/security/advisories/new)
或 issue 私信维护者。维护者有权删除评论、锁定 issue、封禁屡次违规者。

本准则改编自 [Contributor Covenant](https://www.contributor-covenant.org/) 2.1。

# Code of Conduct

## Our pledge

We as members, contributors, and leaders pledge to make participation in our community a
harassment-free experience for everyone, regardless of age, body size, visible or invisible
disability, ethnicity, sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race, religion, or sexual
identity and orientation.

## Expected behavior

- Be patient with newcomers — the target users of this project are people who just installed
  Windows for the first time
- Provide environment details when reporting issues; it is what lets others help you
- Criticize ideas, not people; evidence and reproduction steps help
- Accept "this is Windows behaving that way, not a bug" as a possible answer,
  and check SPEC §13 (decision log) first

## Unacceptable behavior

- Harassment, personal attacks, discriminatory language
- Publishing others' private information
- Spam, off-topic advertising in issues
- Exaggerating security issues to pressure for bounties

## Scope

Applies to all project spaces (issues, PRs, discussions) and public spaces
when representing the project.

## Enforcement

Report via [private vulnerability reporting](https://github.com/xinghe-labs/devkit/security/advisories/new)
or by contacting the maintainer. Maintainers may remove comments, lock issues,
and ban repeat offenders.
